# se-voir-autrement
Écrire sur soi à partir d'une image de soi. Travailler la confiance en soi par le détour de l'intime — l'iris, fragment du visage invisible au quotidien, révélateur d'une présence unique au monde. Comprendre qu'une image n'est qu'une grille de nombres. Apprendre à lire, modifier et analyser ces nombres avec Python.
